# Kiln 0.2.0-dev.29.21

This patch gives AMD FSR 4 a new try at dark scenes: Kiln no longer adds six Vulkan extensions to the game's graphics device for it. It also fixes a moment in which a Kiln task's crash could let its mod start another task. Everything else is as in 0.2.0-dev.29.20.

**Not checked in a real game yet.** This patch passed Kiln's tests. None of it has been seen in a real game yet, FSR 4's dark scenes on an RX 9000 card included. If something looks or works wrong, tell us on GitHub or Discord with `kiln/logs/kiln.log`.

## Players

- **AMD FSR 4 should no longer draw dark scenes too dark.** On 0.2.0-dev.29.19 and 0.2.0-dev.29.20, FSR 4 drew dark scenes too dark on an RX 9070 XT, even with every input it gets each frame the same as OptiScaler's. OptiScaler's own Vulkan FSR 4, from the same AMD file, ran right on the same card, on a game device without six Vulkan extensions that Kiln added for FSR 4 (as AMD's sample does): cooperative matrix, FP8, compute-shader derivatives, 8-bit storage, the memory model and maintenance4. Kiln no longer adds them. FSR 3.1, Intel XeSS and Kiln's own drawing need none of them. AMD FSR's "Auto" stays on FSR 3.1 until a tester confirms FSR 4 on an RX 9000 card. To try FSR 4, choose **FSR 4 (experimental)** under **AMD FSR version** (the Kiln menu's Graphics tab, or the launcher's Settings &gt; Graphics card). For testers: the line `fsr4ext on` in `kiln/control/amd` in the game folder puts the six extensions back from the next game start, for a comparison. kiln.log says at the game's start which way the device was made, and the AMD FSR set-up line names it. Details: [graphics.md](../graphics.md#upscaler-behind-the-games-fsr-3-how-it-works-020-dev2918).

## Fixed

- **A Kiln task's crash stops its mod first.** When a mod's task crashed, Kiln published the task's failure before it stopped the mod, so for a moment the mod could still start another task (from the task's own `done`, for example). Kiln now stops the mod's tasks first, then publishes the failure. Details: [services/tasks.md](../services/tasks.md).
