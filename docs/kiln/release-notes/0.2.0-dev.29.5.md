# Kiln 0.2.0-dev.29.5

A quick fix for 0.2.0-dev.29.4: Auto Doors works again next to Item Skill Descriptions. The SDK stays at 0.2.0-dev.29. Everything else is as in 0.2.0-dev.29.4.

## Fixed

- **Auto Doors works again when Item Skill Descriptions is on.** 0.2.0-dev.29.4 started Auto Doors 1.1.0 a few seconds late when Item Skill Descriptions was on, so that both could change the same game function. Started that late, Auto Doors found two of the game functions it needs already hooked by Kiln in a form it does not accept, so it stayed off. Kiln starts it early again, before its own hooks, as in 0.2.0-dev.29.3. With both on, Item Skill Descriptions' tooltips stay vanilla again for now (the same as in 0.2.0-dev.29.3); a fix that lets both work comes in a later patch. Shroudlink's K tab beside Auto Doors keeps working.

## Mod authors

- 0.2.0-dev.29.5 ships the launcher and the runtime only; keep using the 0.2.0-dev.29 SDK (mod API 0.2.4).
- The compat rules' `defer` action stays; Kiln no longer ships a rule that uses it.
