# Kiln 0.2.0-dev.31.11

## Players

- **Mod windows can open where they belong.** Mods can now place their screens and windows, for example Grimoire opening beside Better Spells, and can remember where you moved them across game starts, always kept inside the screen (#146). Thanks Fuzen777.

## Modders

- **Screen and window placement (mod API 0.2.20).** `UiScreenOptions.Position`, `MoveTo` / `Resize` (applied once, on the next frame), `Placement`, and an opt-in `RememberPlacement` that keeps where the player left a screen or window across game starts, always inside the screen (#146). The TestKit models placement; it assumes the window lands exactly where asked. Two screens or windows that remember under the same mod and id share one entry.

## Not yet seen in a real game

- The game's own window placement, title bar and dragging with these options, the Grimoire and Better Spells example as two real mods, and the save at quit: Kiln writes a move at once when the game unloads its mods, so only a crash within about a second of a drag loses that last move. Managed and TestKit tests cover the rest.
