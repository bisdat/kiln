# Kiln 0.2.0-dev.31.2

A patch for 0.2.0-dev.31.1: creative mode's effects can now be switched on and off one by one, Crucible packs can be shared by link without a Discord login (and saved to a file on the Steam Deck), the launcher opens Kiln Web Admin for a server, and Kiln supports EMF 0.6.22. Mod API 0.2.18.

## Players

- **Creative mode, one effect at a time.** In creative mode, each effect (invulnerability, no consume, unlimited flight, free building, mining and the rest) has its own switch on the creative menu's Rules page (F7). The page shows whether each effect is on and, when it can't be changed, why: the server's creative preset or rules, a server limit that cancels it out, or another mod's rule. `/creative effect <name> on|off [player]` does the same from chat, and `/creative status` lists the effects. Turning creative on still switches every effect on, as before.
- **Share a pack without a Discord login.** Crucible's Share can now make an unlisted link or code without signing in, on desktop and Steam Deck. Anyone with the link or code can open and install it; unlisted packs aren't in the public gallery. The launcher keeps a private owner key on this device so you can update the same link later. Publishing to the public gallery still needs Discord sign-in, and packs you shared while signed in stay tied to your account. See frostdev.io/kiln/privacy for what is kept.
- **Steam Deck: save a pack as a file.** When QR sign-in fails in Game Mode, Crucible's share screen offers to save the pack as a local `.kilnpack` file instead, before sign-in or after Back from the QR error.
- **Mod checks against the game's own Kiln.** When a game is selected, the launcher's mod preview now checks native mods against the Kiln runtime installed in that game. If that version can't be read, it uses the launcher's own version and says so in the preview.

## Server admins

- **Open Kiln Web Admin from the launcher.** A server running the Kiln Web Admin mod gets an "Open web panel" button in Servers > Overview. The launcher reads the panel's address and certificate from the mod, forwards it over SSH for remote servers, and signs you in with Kiln.Admin's one-time login.
- **Creative effects for admins.** Kiln.Admin's creative ops can read and set each player's creative effects, with the same permissions as `/creative`.

## Modders

- **Mod API 0.2.18.** New: `Creative.SetEffect(EntityId, string, bool)`, `Creative.Effects(EntityId)` and `CreativeEffectState` (Kiln.Rules). No native ABI change.
- **EMF 0.6.22 (#141).** Kiln accepts EMF's SDK/header v49 next to v48. `path_find` and `enemy_move` still refuse (fail closed), and Lua startup under 0.6.22 hasn't been checked yet.
- **Items.GiveEquip and ammo (#139).** Arrows, spells and fishing bait given straight into equipment now go into a checked, free cell of the player's backpack, never into a spare Equipment page cell (the game dropped those at the next load). A stale or shared selected cell is refused with `SlotChanged` before anything changes.

## Not yet seen in a real game

- Creative effect toggles in a real game client.
- Sharing without a login and the Deck's save-as-file on a real Steam Deck.
- The web panel button against a live Web Admin server.
- Whether #139's change keeps the item after a reload.
