# Kiln 0.2.0-dev.29.9

A patch for 0.2.0-dev.29.8: keys can be unbound in Kiln's menu, and kiln.log records what EMF mod windows do. The SDK stays at 0.2.0-dev.29. Everything else is as in 0.2.0-dev.29.8.

## Fixed

- **Keys can be unbound in Kiln's menu.** The Keys page had only "click to rebind" and Reset; leaving an action without a key meant editing `kiln/config/keybinds.json` by hand. Each action now has an Unbind button (not Kiln's own menu key, which would lock the menu away), and the page's instructions wrap instead of being cut off at the menu's width.

## Changed

- **kiln.log records what EMF mod windows do.** When an EMF mod opens a window, kiln.log now says so with its title and the rows you can click, and later notes real changes, each click the mod receives and when the window closes, with limits so it stays short. A support report then shows whether a window like EMF Expeditions' opened, what it listed and whether Send was clicked.

## Mod authors

- 0.2.0-dev.29.9 ships the launcher and the runtime only; keep using the 0.2.0-dev.29 SDK (mod API 0.2.4).
