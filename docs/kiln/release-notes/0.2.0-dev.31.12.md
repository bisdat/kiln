# Kiln 0.2.0-dev.31.12

## Players

- **Crafting from linked chests works in every crafting menu (#132).** With a mod that links your chests in other bases (such as Streamlined Logistics), crafting stations like the decoration table, NPCs and the inventory now craft from those chests without Cross-Base Storage. Native mods that patch the game's payment (Building Tools, Unified Tweaks Live) no longer switch it off. Thanks Fuzen777 for the testing and logs, and CharosDX's Cross-Base Storage (MIT) for the map of the game's stock paths.
- **Mod spell and arrow rows re-show the HUD list (#140).** Cycling to a quiver or spellbook mod's arrow or spell shows the HUD list again, like the game's own rows. Thanks Fuzen777.
- **Fast spell switches keep the slot in Append mode too (#145).** With a mod that adds rows to the HUD spell or arrow list (Append, including Player Storage's ammo), a fast pick of the spell or arrow a mod had just swapped out of the backpack no longer empties the slot; it raises `Picked` for the mod that lists it, as Replace already did since 31.10. Thanks Fuzen777.
- **Map markers reach players on dedicated servers.** Kiln's network layer pads every message to whole 4-byte words, and the markers channel refused those padded messages, so a joined Kiln player never got markers. Both ends need 31.12.
- **A mod you switch off in your own ShroudForge folder stays off.** A mod you switched off in your Kiln profile no longer runs from a folder you put into ShroudForge's mods folder yourself: Kiln-hosted ShroudForge skips it for that start and leaves your files as they are. Where Kiln can't skip it, the status says it runs and how to turn it off.
- **Mods that another loader still runs say so.** A mod you switched off in your Kiln profile that EMF's, Greeneye Loader's, Shroudtopia's or Flame's own loader still runs from a folder of yours, or whose DLL you also put in as a dinput8 proxy, no longer shows as "disabled": Kiln now says it runs, where from, and how to turn it off in that loader.
- **Starts with ShroudForge mods are fast again.** A start with ShroudForge mods reuses the last prepared pass instead of redoing it every time (HTR saw 11 minutes per start): the first 31.12 start runs one pass, then later starts reuse it until a mod or the game changes. Thanks HTR.
- **"Update game" banner.** Play now shows a clear "Update game" banner when the game's Kiln is older than the launcher's, with both versions and a one-click update. Thanks HTR for the feedback.

## Modders

- **Linked chests feed fills, building and locks (mod API 0.2.21).** `CraftSourceOptions.Fills` lets a link feed production stations' "+1"/"+10" (and `Stations.Fill` with `UseLinkedSources`; `FillInput.Linked`, `StationResult.FromLinked`). `CraftSourceOptions.Building` lets the Construction Hammer count and place blocks from it, and the build menu counts it (capabilities `crafting.build_sources`, `crafting.build_ui`). `CraftSourceOptions.Locks` lets a lock that needs an item, such as a lockpick, open from a linked chest and take the item there (`Crafting.LockSourcesCapability`, `items.lock_sources`, #147). All three are off by default. The bag and the base's own chests always pay first, all or nothing; a linked chest of the base you build in counts once, as the base's. They need a Kiln server or host, and a Kiln client for the station buttons, the build cursor and the build menu (a lock opens from links for any client; a Kiln client's prompt shows it unlocked too). Thanks Fuzen777 for the requests and write-ups.
- **Server camera requests reach joined Kiln players.** `camera.remote`'s messages had the same trouble as the markers: Kiln's network layer pads them to whole 4-byte words, and the camera wire refused its padded Welcome, Ended and most Acks, so a joined client's camera link never came up (the lab transport pads nothing). Both ends need 31.12.
- **`Items.GiveEquip` gives eternal spells and arrows into their slot (#139).** They are created once with their own item entity in a backpack cell and equipped there; a replaced eternal keeps its entity or is taken (capability `items.give_equip.instance_ammo`). Thanks Fuzen777.
- **C ABI (appended):** `KilnCraftSourceRequest` flags (`KILN_CRAFT_SOURCE_LOCKS`, `_FILLS`, `_BUILDING`), `source_stock` flags, `KILN_STATION_FILL_LINKED`, `KilnStationPlan.linked[]`, `KilnStationResult.from_linked`, and table members `set_lock_stock`, `lock_asks`, `set_build_stock`. An older 32-byte request is still accepted.

## Not yet seen in a real game

- Crafting, fills and building from linked-only stock without Cross-Base Storage, next to Building Tools, Unified Tweaks Live and Cross-Base Storage, and on a dedicated server with a joined Kiln client. The root cause was read from the game's code; native host tests and signature tests cover each path.
- Locks from linked chests, eternal spells given into their slot after a save and load, the HUD list reveal, and markers and server camera requests on a dedicated server with a joined client.
