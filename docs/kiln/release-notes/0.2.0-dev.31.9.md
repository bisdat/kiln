# Kiln 0.2.0-dev.31.9

## Players

- **Inventory marks stay out of the game's menus.** Marks that mods put on inventory slots no longer draw over the game's item menu (right-click an item: Equip, Salvage, Delete), drop-downs or context menus. A slot under an open menu shows no mark until the menu closes; the other slots keep theirs (#117). Thanks Fuzen777.

## Modders

- **`GameScreen.PopupOpen` (mod API 0.2.19).** True while one of the game's popups covers its UI in that screen's frame. `Ui.Inventory` does not ask `MarkWhen` rules for covered slots. C: the new tail member of `kiln_ui.h` and capability `ui.popups` (off on a game build where the popups can't be read; marks then draw as before). The TestKit models no popups: `PopupOpen` is false.

## Not yet seen in a real game

- Whether every popup kind (item menu, drop-down, context menu) is caught, and how marks look in a popup's first frame. The popup layout was read from the game's code; the UI host and managed tests cover the rest.
