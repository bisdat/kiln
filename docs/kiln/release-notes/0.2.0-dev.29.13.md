# Kiln 0.2.0-dev.29.13

A patch for 0.2.0-dev.29.12: Skill Search's search box and the In Game Ping System's markers work again. The SDK stays at 0.2.0-dev.29.11. Everything else is as in 0.2.0-dev.29.12.

## Fixed

- **Skill Search and the In Game Ping System work again.** Both come as an EML mod (its `mod.json` and Lua) with a Shroudtopia module beside it, the part that draws Skill Search's search box and the Ping System's markers. Kiln's Library adds such a mod as an EML mod, and with a profile Kiln only loaded the Lua half: the Shroudtopia module never started unless Shroudtopia's drop-ins were on. Kiln now also loads the Shroudtopia module of an EML mod that is switched on, so both halves run. If you removed its `mod.json` and `src` folder as a workaround, you can add the mod again as it came.

## Mod authors

- 0.2.0-dev.29.13 ships the launcher and the runtime only; keep using the 0.2.0-dev.29.11 SDK (mod API 0.2.5).
