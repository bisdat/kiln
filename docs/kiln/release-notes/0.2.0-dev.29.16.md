# Kiln 0.2.0-dev.29.16

A patch for 0.2.0-dev.29.15: Kiln's mark next to its line in the main menu is back. The SDK stays at 0.2.0-dev.29.15. Everything else is as in 0.2.0-dev.29.15.

## Fixed

- **Kiln's mark shows in the main menu again.** Since 0.2.0-dev.29.15 the small Kiln mark before "Kiln 0.2.0-dev… · N Mods Loaded" at the bottom of the main menu was missing, leaving a gap. Kiln's overlay draws an image only once it is on the graphics card, and in the main menu the mark was the only thing to draw, so the overlay skipped the frame that would have put it there. The overlay now sends new images to the graphics card even in a frame where it draws nothing else. The same could hide a mod's image when it was the only thing a mod drew.

## Mod authors

- 0.2.0-dev.29.16 ships the launcher and the runtime only; keep using the 0.2.0-dev.29.15 SDK (mod API 0.2.7).

Kiln's UI host tests and the Windows build of kiln-ui. Not yet seen in a real game.
