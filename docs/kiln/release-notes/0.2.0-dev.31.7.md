# Kiln 0.2.0-dev.31.7

## Players

- **Download missing mods for a pack.** A pack you installed from Crucible that is missing a mod from your Library now says so before you load it, and offers "Download missing mods". It downloads only what's missing for your installed version, checked like an install, and changes nothing else: your profile, the pack's version, settings and game folder stay as they are. It works while the game runs, and from Settings → Profiles (the pack's menu) too. A pack installed from a file repairs from that file.

## Known limits

- The Steam Deck's pack preview doesn't offer Download missing mods yet.
- When something is still missing afterwards, the message lists mod ids instead of names.

## Not yet seen in a real game

- Download missing mods against the live Crucible service (covered by the launcher's interface tests and kiln-manage's pack tests).
