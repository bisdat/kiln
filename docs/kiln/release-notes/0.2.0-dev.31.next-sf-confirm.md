# Kiln 0.2.0-dev.31.next: ShroudForge mod news in game

## Players and server admins

- **What a ShroudForge mod tells you now shows in game.** A ShroudForge mod cannot draw on the game's screen, so it sends its messages to ShroudForge's news feed, which ShroudForge's own window shows. When Kiln runs ShroudForge, there is no such window, and Kiln showed none of those messages. Now each new message pops up over the game as a Kiln message for 10 seconds, at most three at once; a long one is shortened there. The newest three also stay in that mod's details, in full, on Kiln's ShroudForge page (F9). When a mod opens ShroudForge's window (Altar Cleanup's "Open ShroudForge when done"), Kiln's page opens on that mod. For a mod with shortcuts, the page also says that its keys work once the menu is closed. Thanks to netjunk for the report on Altar Cleanup's "Ask before cleaning up": the first press scanned, but its result and "press the cleanup key again within 60 seconds" showed nowhere.

## Modders

- `shroudforge.notifications.publish` under hosted ShroudForge: Kiln.Ui reads the notices from the runtime's `state.json` `events` section (ShroudForge's `paths.state` folder), where the runtime stores them. It toasts each notice that is new or published again during this game, as long as Kiln answers ShroudForge's menu (no ShroudForge window running). At most 3 notice toasts are on screen at once, newest first; a notice that finds no room shows only in the mod's details. A toast is plain text (line breaks, tabs and control characters become spaces) in at most 4 lines of 96 columns. Entries with neither a title nor a message (ShroudForge's own install and update records) are not shown. The notice's level picks the toast's look: `error` is Error, `info` is Info. ShroudForge's API also names `success`, `warning` and `update`, but its event schema refuses them (fork pin 6cf01443), so such a publish fails in ShroudForge itself. Kiln writes nothing to ShroudForge's folders. It opens `state.json` only when the file changed, briefly and with delete sharing, to stay out of the way of ShroudForge's writes. Kiln's interpreter (kiln backend) keeps its own notices and is unchanged.
- `shroudforge.ui.toggle_modloader()` under hosted ShroudForge still toggles Kiln's ShroudForge page like F9. When it opens the page, Kiln chooses the mod whose notice came within the last 3 seconds. It reads the notices again for up to 1.6 s, since a mod may publish just after it asks.
- Key presses still don't reach ShroudForge while Kiln's menu has the keyboard (0.2.0-dev.31.18). ShroudForge's own runtime counts none while its window is in front either.

## Not yet seen in a real game

- The toast and the page's news for Altar Cleanup's scan result in netjunk's hosted world. Whether Altar Cleanup publishes its "press the key again" question as a notice, rather than only logging it, comes from its Nexus page, not from its Lua.
