# Kiln 0.2.0-dev.31.next: ShroudForge mod news in game

## Players and server admins

- **What a ShroudForge mod tells you now shows in game.** A ShroudForge mod cannot draw on the game's screen, so it sends its messages to ShroudForge's news feed, which ShroudForge's own window shows. When Kiln runs ShroudForge, there is no such window, and Kiln showed none of those messages. Now each new message pops up over the game as a Kiln message for 10 seconds. The newest three also stay in that mod's details on Kiln's ShroudForge page (F9). When a mod opens ShroudForge's window (Altar Cleanup's "Open ShroudForge when done"), Kiln's page opens on that mod. For a mod with shortcuts, the page also says that its keys work once the menu is closed. Thanks to netjunk for the report on Altar Cleanup's "Ask before cleaning up": the first press scanned, but its result and "press the cleanup key again within 60 seconds" showed nowhere.

## Modders

- `shroudforge.notifications.publish` under hosted ShroudForge: Kiln.Ui reads the notices from the runtime's `state.json` `events` section (ShroudForge's `paths.state` folder), where the runtime stores them. It toasts each notice that is new or published again during this game, at most 3 at a time, as long as Kiln answers ShroudForge's menu (no ShroudForge window running). The notice's level picks the toast's look: `warn` is Warning, `error` is Error, `success` is Success, anything else is Info. Kiln writes nothing to ShroudForge's folders. Kiln's interpreter (kiln backend) keeps its own notices and is unchanged.
- `shroudforge.ui.toggle_modloader()` under hosted ShroudForge still toggles Kiln's ShroudForge page like F9. When it opens the page, Kiln chooses the mod whose notice came within the last 3 seconds. It reads the notices again for up to 1.6 s, since a mod may publish just after it asks.
- Key presses still don't reach ShroudForge while Kiln's menu has the keyboard (0.2.0-dev.31.18). ShroudForge's own runtime counts none while its window is in front either.

## Not yet seen in a real game

- The toast and the page's news for Altar Cleanup's scan result in netjunk's hosted world. Whether Altar Cleanup publishes its "press the key again" question as a notice, rather than only logging it, comes from its Nexus page, not from its Lua.
