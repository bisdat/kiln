# Kiln 0.2.0-dev.31.4

## Players

- **Got a code works without a profile.** The launcher's "Got a code" link for Crucible packs is there on Play even when no local profile is loaded, for example when the game uses a profile from another Kiln data folder or Kiln isn't in the game yet. Sharing still needs a loaded profile.
- **Create an empty local profile.** When no profile is loaded, Settings → Profiles offers "Create empty local profile…". It only saves the profile in this launcher's data folder and doesn't change what the game has loaded.
- **A new profile never takes over another folder's profile.** A new profile (from Settings or a pack install) could get the same ID as a profile from another data folder that the game still uses, and the launcher could then rewrite the game's profile file. Kiln now picks a different ID (with the same name) in that case.
