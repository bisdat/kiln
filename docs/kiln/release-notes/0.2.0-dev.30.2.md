# Kiln 0.2.0-dev.30.2

Kiln can now run ShroudForge mods itself, as a new choice in Settings that is off by default. This patch also makes Crucible look and read like the rest of Kiln, lets you install a pack without starting the game, fixes Kiln's overlay next to ReShade, and has Pack Studio read the game's items by itself.

**Not checked in a real game yet.** These changes passed Kiln's tests. If something looks wrong, tell us on GitHub or Discord with `kiln/logs/launcher.log` or `kiln/logs/kiln.log`.

## Kiln mode: Kiln can run ShroudForge mods itself

Kiln can now run ShroudForge mods itself. **Kiln mode** is a new backend for ShroudForge mods: Kiln reads and runs them
on its own interpreter, with no separate ShroudForge runtime in the game. **It is off by default and stays off unless
you turn it on**: Kiln's bundled ShroudForge remains the default for every install, new and existing.

**New, and not checked in a real game yet.** Kiln mode is new in this release. It passed Kiln's tests, but it has not been checked in a real game yet. To try it, choose **Kiln's interpreter** on the ShroudForge card in Settings; it applies from the next start, and your choice is per game. If something looks wrong, choose Kiln's bundled ShroudForge again and tell us on GitHub or Discord with `kiln/logs/kiln.log` and `kiln/state/sfi.json`.

### Players

- **Choose how ShroudForge mods run.** Settings has a new **ShroudForge** card with three choices: **Kiln's bundled
  ShroudForge** (the default), **My installed ShroudForge** (replaces the old "Use my installed ShroudForge" switch,
  which keeps working) and **Kiln's interpreter** (kiln mode). The choice
  is per game and applies from the next start; the card also shows what the last start used.
- **A warning before Play, when it matters.** In kiln mode the launcher checks your ShroudForge mods before the game
  starts. A mod Kiln cannot run whole is skipped for that start, with its reason, and a dialog lists it before the game
  opens. Cancel is the default; nothing is switched off or deleted.
- **"Do not save" when a mod with save data is off.** Some mods keep data in your saves (Quiver & Spellbook's ammo,
  for example). If such a mod is off for a start, the warning before Play, a banner in the game, a badge on the mod's
  row and a marker on the pause menu's Mods entry say: do not save while this mod is off; restore it and restart first.
- **The mod menu key works in kiln mode.** ShroudForge's menu key (F9 by default) opens Kiln's ShroudForge page in the
  game: the mods of this start, their settings and their action buttons. Settings changed there apply at the next start.
- **Switching back is one choice.** Choose Kiln's bundled ShroudForge on the card. Your mods, their settings and your
  own mod folders stay as they were.

What kiln mode does not do yet, so a few mods run with a feature off:
- Mod keyboard shortcuts (`shroudforge.input`) answer "not pressed" in kiln mode for now.
- In-game world changes (entity queries and writes, props, voxels, in-game asset reads) answer "unavailable"; mods that
  check for them keep running without that feature.
- Mod DLLs load at the start; a DLL Kiln has no reviewed rule for is skipped with the reason.
- Kiln mode follows the ShroudForge 1.7.9 mod API; mods that need ShroudForge 1.8 keep working on the default backend.

### Mod authors

- Your ShroudForge mods need no change for kiln mode. Kiln runs `mod.json` / `extended.mod.json` packages, their
  startup pass, their Lua runtime and their DLLs. Functions Kiln does not provide yet give ShroudForge's own
  "unavailable" answer (`nil`/`false` plus a reason), never a surprise `nil`: guard optional features with
  `runtime.has` or `pcall` as you would for ShroudForge.
- Differences you can see: a callback running over 10 s of Lua time ends that mod for the start; compute-heavy Lua is
  slower (a tight arithmetic loop about 2.5 times); live reload takes Lua-only mods, and an edited mod needs a restart;
  settings changed in kiln mode apply at the next start.

## Also in this patch

### Players

- **Share to Crucible asks first.** The first time you share a profile, Kiln shows what goes up (the mod list and the mods' files Crucible doesn't have yet, with about how much), what stays on your PC (your mod settings and your own data edits), and that your saves, worlds and characters are never sent. The pack is link-only: only people you give the link or code to can open it. **What is Crucible?** next to the button explains the rest. Updating a link you already shared doesn't ask again. Thanks to netjunk for the suggestion.
- **Install a pack without playing.** The pack preview has **Install** next to **Install and play**: it adds the pack as its own profile without loading it or starting the game, so it works while Enshrouded is running.
- **No more two profiles with the same name.** An installed pack's profile is named after the pack and its creator, like "My mods (Felup's pack)", and you can change the name before installing. A name you already use gets a number.
- **The pack preview shows Crucible's checks.** "Checks: passed", things to look at, or "still running on Crucible" with **Refresh**, for packs from a code or link too (before, only for a dropped file).
- **Crucible looks like Kiln.** The share button, its popovers, pack codes, the "Pack changed" badge, the pack preview, the update screen, the Deck's code and Pack Studio now use Kiln's ember and gold instead of blue and purple.
- **A clearer pack preview.** The pack's name shows once, the mod list no longer scrolls inside the dialog, and the preview says "Tick "I trust" first." under the trust box so you know why Install waits. A pack that is still uploading no longer shows an empty download line, and "Needs Kiln 0.2.0-dev.31 or newer" no longer shows a stray ">=".
- **Sharing while offline** now says to check your internet or use **Save as file**. Before, it told the person sharing to ask a friend for the file.
- **Pack updates** show versions (1.0.0 → 1.1.0) on the Play banner as well as on the update screen, and the update screen says why Update waits ("Choose for each setting first."). "1 mods" is now "1 mod", and "+1 added" is "1 added".
- **Kiln's overlay next to ReShade.** Kiln's overlay crash guard no longer turns the overlay off after slow first frames (ReShade's Vulkan layer compiling its effects), and when nothing of Kiln's overlay reaches the screen, the Mods entry shows the game's own Mods rows instead of an invisible menu. When Kiln's drawing steps aside for another overlay (NVIDIA Streamline, OptiScaler), kiln.log names it. Thanks to Eris and netjunk for the reports.
- **The Community tab's docs link** opens Kiln's wiki. Before, it opened a page that doesn't exist. Thanks to netjunk for the report.

### Mod authors

- **Pack Studio reads the game's items by itself.** When it opens, Pack Studio reads the game's items, so the Items, Recipes and Loot pickers list the game's entries without any command-line step. If Steam is updating the game it says so and offers a **Build the game catalog** button. Thanks to netjunk for the report.
- **Pack Studio hides the game's old and test entries.** The Items, Recipes and Loot pickers leave out game entries whose names mark them as deprecated, unused, work in progress or test (Z_..., _DEPRECATED, DONOTPLACE, _TEST, _OLD...). Entries the game's own recipes and stations still use stay listed, and so does the game's **Water**, which is shown as "station tank water". **Show hidden game entries** lists the rest, and a hidden name you type or paste still works: the data check adds a note. Thanks to netjunk for the suggestion.
- Pack Studio's "Lint" line is now **Data check**, and the publish checks show as small badges.
