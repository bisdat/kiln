# Kiln 0.2.0-dev.31.14

## Players

- **Linux: a black launcher window from a broken font cache gets a way out.** When the launcher's window stays black because the system's font cache is broken (seen on ZorinOS), it now shows a native hint with "Fix it and restart" (moves the cache aside, rebuilds it with fc-cache -r and restarts the launcher), "Keep waiting" and "Quit". It shows once per chain of starts, so it never locks out the launcher's other fallbacks. Thanks PhxAs5as5in.
- **Open web panel works with Kilnwarden.** Kiln Web Admin is now called Kilnwarden (mod id `kilnwarden`), and the launcher's "Open web panel" on a server's Overview now shows for it and signs you in. Kiln Web Admin 0.1.0 test builds (`kiln-webadmin`) keep working. If both are installed, Kilnwarden stays off until you delete `kiln/mods/kiln-webadmin/` (its kiln.log says so), and the button opens the old copy's panel until then.

## Modders

- No API change (mod API stays 0.2.22). Kiln's analyzers now know `Crosshair.Available` and `PadInput.Available` as capability guards (the 31.13 table missed them).

## Not yet seen in a real game

- Kilnwarden's "Open web panel" against a real server, and the font-cache hint on a real broken cache.
