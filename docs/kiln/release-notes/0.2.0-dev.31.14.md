# Kiln 0.2.0-dev.31.14

## Players

- **Open web panel works with Kilnwarden.** Kiln Web Admin is now called Kilnwarden (mod id `kilnwarden`), and the launcher's "Open web panel" on a server's Overview shows for it again and signs you in. Kiln Web Admin 0.1.0 test builds (`kiln-webadmin`) keep working. If both are installed, Kilnwarden stays off until you delete `kiln/mods/kiln-webadmin/` (its kiln.log says so), and the button opens the old copy's panel until then.
