# Kiln 0.2.0-dev.29.1

A quick fix for 0.2.0-dev.29: players with Kiln could not join a world run by Kiln. Everything else is as in 0.2.0-dev.29.

## Fixed

- **Joining a Kiln world with Kiln works again.** In 0.2.0-dev.29 every player with Kiln who joined a world run by Kiln (a world a friend hosts, or a dedicated server) was turned away after a few seconds with "Your Kiln handshake did not complete before admission timed out", even with every mod switched off. The server held each joining Kiln player for its mod check, and the joining game only sent its side of that check once its world was running, which the hold prevented. The joining game now answers while it is held. Update Kiln on both sides: the host or server, and every player.
