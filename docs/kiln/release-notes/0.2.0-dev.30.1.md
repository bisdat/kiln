# Kiln 0.2.0-dev.30.1

A small patch for 0.2.0-dev.30: the launcher no longer asks for clipboard access after an update, and ShroudForge 1.8's glider pitch works under Kiln.

**Not checked in a real game yet.** These changes passed Kiln's tests, and the glider fix ran on a lab server with Kiln and ShroudForge 1.8.1. If something looks wrong, tell us on GitHub or Discord with `kiln/logs/launcher.log` or `kiln/logs/kiln.log`.

## Players

- **No clipboard prompt after updating.** After the update to 0.2.0-dev.30, Windows could show "tauri.localhost wants to see text and images in the clipboard". That was Crucible looking for a copied pack code, which it no longer does when the launcher starts or updates. **Got a code?** still fills in a code you copied, now without a prompt, and has a **Paste** button. It only ever picks up text that looks like a Crucible code or link. Thanks to netjunk for the report.
- **ShroudForge's glider pitch works under Kiln.** ShroudForge 1.8's glider pitch patch, used by ShroudForge Unlimited Flight's "Upward Gliding", said "Native glider pitch control is unavailable" under Kiln. Kiln's own glide steering hook now goes in only when a mod asks for it, and ShroudForge now accepts the game file beside Kiln's hooks. With Kiln's Creative Mode glider in use, ShroudForge still declines its patch (the two would steer the same glider); nothing breaks.
