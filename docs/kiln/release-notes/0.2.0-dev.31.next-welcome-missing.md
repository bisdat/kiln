## Players and server admins

- **Hosting your own world no longer reports your own mods as missing.** When you joined a world you host, kiln.log listed your ShroudForge, Flame and other non-Kiln mods as "missing" (for example `welcome from srv-…, missing creative, altar-cleanup, …`), although your game was running them. Now a joining player's list of missing mods counts every kind of mod the game has (Kiln, native, ShroudForge, Flame, EML, EMF, Green Eye and the others). It compares each mod the way the server advertises it, so its logs and your settings don't count as a difference. Your own hosted world never lists anything as missing. kiln.log names the side: `welcome from your hosted world (srv-…, this game), nothing missing`, or `welcome from server srv-… "Name", missing … (this game lacks them or has another version)`. The launcher's Play page no longer offers a modpack for your own hosted world, also after a join recorded by an older Kiln.

## Modders

- `kiln/state/last-server.json` gains `hosted` (boolean, default false): the answer came from this game's own hosted world, and `missing` is empty. In other answers `missing` now covers other engines' mods too, each compared by the hash the server advertises (`AdvertiseIdentity.cs` rules). No API change.
