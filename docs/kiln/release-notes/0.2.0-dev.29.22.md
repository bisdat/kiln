# Kiln 0.2.0-dev.29.22

This patch brings Tab completion for Kiln's commands in the game's chat, by bisdat, on by default. Before you save or send a support report you now see what is in it, and you can leave other mods' logs out. Reports also take out other players' names and more personal details. Removing a mod keeps its settings unless you ask. ShroudLink's chest names no longer scan the game's memory over and over, mods for Enshrouded ModLoader start in that loader's order, and the Linux launcher draws lighter where WebKit cannot composite. Everything else is as in 0.2.0-dev.29.21.

**Not all of it checked in a real game yet.** This patch passed Kiln's tests. bisdat tested Tab completion in the game on Windows 11, in a hosted world. On 0.2.0-dev.29.21, CarryOn and Belt Lantern each started on their own in a real game. The two together, in this patch's start order, have not been seen yet. Not seen in a real game yet: ShroudLink's new chest-name lookup, and the launcher's report view, its new redaction and "Remove its settings too" on a player's PC. If something looks or works wrong, tell us on GitHub or Discord with `kiln/logs/kiln.log`.

## Players

- **Tab completion in the game's chat, by bisdat.** In the HUD chat and the Social page's chat, start a line with `/` and a list of matching Kiln commands shows above the field. Tab puts the first one in, and Tab again goes on to the next. Once Tab has put one in, Up and Down go through the list, and Esc closes it. Only commands you're allowed to use are offered, since the server answers with your own permissions. It needs Kiln on the server, or your own hosted world; anywhere else, Tab stays the game's own. It's on by default. To turn it off, switch off "Chat completion" in the launcher's Settings (Kiln's settings, In the game), or put `"ui": {"chatCompletion": false}` in kiln.json, then restart the game. For mod authors: your mod's chat commands show up in the list with nothing to add, offered only to players who may use them. Tested in the game on Windows 11 by bisdat ([pull request 73](https://github.com/frostdev-ops/kiln/pull/73), idea #44). Thanks, bisdat!
- **See what is in a support report before it leaves your PC.** Save report... and Send to Kiln support now show "What's in this report" first: the files, grouped as Kiln's logs, other mods' logs, settings and folder listings, each with a plain line on what it holds and what was replaced in it (for example "your home folder (169 times), player names (3 times)"). You can open summary.txt, and see what a report never holds. Each other mod's log has a "Leave out" box, and one box leaves all of them out. Kiln's own logs, the settings and the listings always stay in: support needs them. On a Steam Deck the check step lists every file as a row. `kilnctl report` takes `--contents` and `--exclude`. Details: [support-report.md](../launcher/support-report.md#whats-in-this-report).
- **Support reports take out more personal details.** Other players' names (a co-op host's friends, a server's players) in Kiln's and ShroudLink's logs now read `<player>`, also where a mod's own line repeats a name. IPv6, MAC and mail addresses are replaced, and so is the value after a secret's name in logs and INI files (`password=`, `token:`, `ApiKey =`). Your own Steam names are now also found in Steam's `localconfig.vdf` and `registry.vdf`, for an account `loginusers.vdf` does not remember, and next to `_` or `-` in a file name. Details: [support-report.md](../launcher/support-report.md#privacy).
- **Removing a mod keeps its settings.** Adding the mod again brings them back. To remove them too, check "Remove its settings too" in the remove dialog (on the desktop and on the Deck). Kiln keeps a copy in its backups folder.
- **ShroudLink's chest names no longer scan the game's memory over and over.** With Kiln, a chest's name comes straight from the game's own name table. Otherwise a short, targeted search runs only when a mod asks for a name it does not know yet. With ShroudLink's assistants on, the endless scans on 0.2.0-dev.29.21 could make the game choppy and freeze on PCs with four threads.
- **Mods for Enshrouded ModLoader start in that loader's order.** Kiln started them in the order of your profile, so Belt Lantern could start before CarryOn and CarryOn then failed to start. They now start in the loader's own order (by id), so CarryOn and Belt Lantern can run together. Details: [engines/dllmod.md](../engines/dllmod.md).
- **Linux: a lighter launcher where WebKit cannot composite.** Some systems (an NVIDIA card on KDE Wayland, for example) turn WebKit's compositing off by themselves, even with the GPU and the DMA-BUF renderer on, and the launcher lagged there. Where WebKit composites nothing, open pages and the header's menus now draw a thin line instead of a blurred shadow, which made scrolling much lighter in our measurements. launcher.log now says at every start whether WebKit composites and, when it does not, which of WebKit's own checks failed, and the support report carries that line. Details: [perf.md](../launcher/perf.md).
- **A game build Kiln does not know (GitHub #99).** The guide now says where the build Kiln checks comes from, what to do with a Steam copy, another store's copy or an older game version, and what `"policy": "any"` in `kiln/kiln.json` does at your own risk. Details: [custom-game-folders.md](../launcher/custom-game-folders.md).
