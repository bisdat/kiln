# Kiln 0.2.0-dev.30.8

A patch for 0.2.0-dev.30.7. Building tools from Kiln mods can now actually change terrain in a real game, EMF mods built with EMF 0.6.20 load, and crafting from linked containers shows in the crafting menus' ingredient rows too. Mod API stays 0.2.16.

**Not checked in a real game yet.** Everything passed Kiln's tests, on Windows where it matters. If something looks wrong, tell us on GitHub or Discord with `kiln/logs/launcher.log` or `kiln/logs/kiln.log`.

## Players

- **Building tools from Kiln mods change terrain (#133).** Every stroke of a Kiln building tool was refused before the game's terraform ran, and a Remove on the primary button also failed the game's material check. Both are fixed; `kiln.log` and the `tools.actions` capability now say why a stroke did nothing. Thanks bisdat.
- **EMF 0.6.20 mods load.** Kiln now speaks EMF 0.6.20 (API v48), so mods that ask for it start. A Lua script that plans a path as a given creature (`as`) gets no path, like every EMF path query on Kiln, instead of a script error. Thanks to matenm.
- **Crafting counts (#132).** Crafting menus now count linked containers and opted-in station outputs in their ingredient rows too, not only in the craft count. A production station's screen (Forge, Kiln, Smelter...) shows the game's own counts in its ingredient rows again, because their transfer buttons move only what your bag and Magic chests hold; its "+1" / "+10" still use station outputs, so a row can read 0 while "+1" lights. Linked dyes are listed with the dyes you have. Thanks Fuzen777.

## Modders

- **Mod API 0.2.16**, unchanged.
- **EMF (kiln-emf).** EmfApi v48: `EmfPathQuery` and `EmfPathResult` grew (56 and 48 bytes); `path_find` still reports unavailable. Mods built with the EMF 0.6.19 and 0.6.20 SDKs both start.
- **Crafting stock.** `set_craft_stock` keeps a count-0 row as "this item, none" (it used to drop it). Kiln.Blocks and kiln-items.dll ship together; a half-updated install loses only the output-based fill on station screens.

## Not yet seen in a real game

- EMF Lua 1.41 and Beastmaster 1.20 on Kiln.
- Kiln building tools in a real game: a stroke removing terrain, an Add with too little material on each input, the brush radius, yields, undo and Add payment.
- Crafting-menu ingredient rows with linked sources at a station, in the inventory and at NPCs; station-screen rows with "+1" lit; the dye order.
