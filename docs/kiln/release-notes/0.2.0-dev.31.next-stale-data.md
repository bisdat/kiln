# Kiln 0.2.0-dev.31.next: stale game data

## Players

- **Kiln no longer keeps an uninstalled mod's changes in your game data.** Kiln, and the ShroudForge that comes with it, start every mod pass from a clean copy of the game's data files. That copy could be taken from game files that another mod loader had already changed. It then kept that mod's changes long after the mod was removed. For one player, Auto Loot Plus's auto-smash stayed for weeks: props broke on their own within 15 m, through walls, with Kiln Auto Loot switched off. Kiln now checks the clean copy against Steam's own list of the game's files before every pass. A copy that doesn't match is set aside (never deleted) and taken again from your game files when those are Steam's. When they aren't, and the copy holds a mod's changes, Kiln changes nothing, and the launcher and kiln.log say: "Your game files still contain changes from a mod that isn't installed. Verify the game files in Steam (Properties > Installed Files > Verify integrity), then start again." Until you do, ShroudForge's mods (and, without ShroudForge, Kiln's EML mods) don't load. A copy that only differs from Steam's list, with no sign of a mod in it, is used as before, and kiln.log says so. Thanks HadToRegister for weeks of reports, and for the Steam file check that found it.

## Modders

- No API change. The working baseline record (`enshrouded.kfc.baseline.json`) now keeps each backup's SHA-1. ShroudForge's prepared record moves to scheme `kiln-sf-prepared 3`, so the first start after this update runs its pass once. kiln-eml accepts scheme 3 as hosted ShroudForge output. A clean copy is refused only when it holds a known mod's program (for now, Auto Loot Plus's auto-smash program and aura) or its resource file is Steam's own with more data after it; without a Steam manifest (a SteamCMD server, a game folder outside a Steam library), only the known programs count. kiln-eml now sets a clean copy it replaces aside in `kiln/eml/backups/outdated/` (the newest one is kept) instead of overwriting it.

## Not yet seen in a real game

- The refusal, the retake and the "used as before" warning on a player's real game folder (Windows, Linux/Proton, Steam Deck), and the first start's one extra read of the clean copy (about 225 MB) after updating.
