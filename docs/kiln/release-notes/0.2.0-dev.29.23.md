# Kiln 0.2.0-dev.29.23

This patch changes only the launcher's save editor: it speaks the launcher's languages, it no longer shows or writes over a backpack it could not read for sure, it shows another mod's hidden items as locked tiles, and its Available skill points are the game's own count. Kiln's game side is the same as in 0.2.0-dev.29.22.

**Not checked in a real game yet.** These changes passed the launcher's tests and were checked against the save of the player who reported them. If something looks wrong, tell us on GitHub or Discord with `kiln/logs/launcher.log`.

## Players

- **The save editor speaks your language.** It showed English in every language. Its texts now follow the launcher's 11 languages; item and skill names stay the game's.
- **The editor no longer guesses where a backpack is.** On a save with another mod's item in it (here Belt Lantern), the editor could show the Backpack as empty ("0 of 40") and would have written new items at a guessed place in the save. It now finds the inventory by the game's own layout. A save it cannot read for sure, or one that holds another mod's data or items Kiln doesn't know, opens read-only and says why. The reporting player's save now opens whole.
- **Other mods' hidden items show as locked tiles.** An item no table knows (very likely Hands-Free Lantern's hidden lantern, in the reported save) shows as a locked tile with a note naming its slot, and Kiln keeps it untouched.
- **Available skill points are the game's own count.** The game doesn't save an "available points" number: it works it out at each load, 2 per level above 1, +1 for each Shroud Root and +3 for each Elixir Well. The editor now shows that count (it can't be edited, since the game doesn't keep it) and won't save a skill tree that spends more than it, which the game would reset completely when the save loads.
