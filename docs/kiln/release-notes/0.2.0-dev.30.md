# Kiln 0.2.0-dev.30

## Fixed

- **The last autosave hitches on hard drives.** On a hard drive a hosted world or a server could still stop for a few seconds at an autosave in 0.2.0-dev.29, while Kiln.Saves wrote, confirmed and tidied up its small mod data files (GitHub issue #39, HadToRegister). Kiln.Saves now does all of that file work on its own thread, so the world keeps running while the drive catches up. The game's own write of the world file waits for Kiln's file instead, so after a crash your mods' data still matches the world it loads. `kiln.log` now says how long each part of a save took and on which thread.
