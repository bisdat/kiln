# Kiln 0.2.0-dev.31.next (GitHub #148)

## Players

- **Building from linked chests works, with or without Building Tools** (kiln#148). With a mod that links chests for building (Streamlined Logistics' Build From Linked Chests), blocks whose material is only in linked chests now show in the Construction Hammer's list with their count, the cursor shows the linked count before you place, the material catalogue counts them under Backpack & Magic Chests, All Materials and the amount sort (as before under Last Used and Favorites), and placing them pays from the bag and the base's Magic chests first (in the game's own order), then from the linked chests. Until now the list and the catalogue missed materials only the links held, and every placement was refused because Kiln turned down the game's placement transaction (kiln.log: "craft transaction did not check out (its accessors)"). With Building Tools 0.34.0, its placements now pay from the links too. If a placement is still left to the game, kiln.log says why as "block placement". Thanks to Fuzen777 for the clear report and logs.

## Modders

- No API change (mod API unchanged). `CraftSourceOptions.Building` links now count in the build menu exactly where the base's Magic chests do. capability `crafting.build_ui` needs one more client symbol (`build/client.NoContainerKey`).

## Not yet seen in a real game

- The hammer's list, the cursor count, the catalogue tabs and a placement paid from linked chests in a hosted world, on a joined Kiln client (dedicated and hosted), with and without Building Tools 0.34.0.
