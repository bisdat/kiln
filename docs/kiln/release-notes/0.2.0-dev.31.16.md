# Kiln 0.2.0-dev.31.16

## Players

- **Typing T in Kiln's search no longer adds a "b".** With ShroudLink's key for its Assistants panel set to T, every "t" typed into the Kiln menu's search (or any Kiln text field) came out "tb": ShroudLink presses B (the game's backpack key) whenever that key goes down, and Kiln typed that B into the field too. Kiln now keeps key presses that a mod sends into the game while one of its text fields is active out of that field, so you get exactly what you typed. On-screen keyboards, key remappers and other programs still type as before. Thanks HadToRegister.
- **Automated stations: the per-ingredient +1 / +n now use your linked chests.** A production station's ingredient rows count what your fill-opted links hold (`CraftSourceOptions.Fills`, for example Streamlined Logistics), and their +1 / +n take from those links when your bag and the base's Magic chests fall short. Your bag and the Magic chests go first, and it is all or nothing. You need a Kiln server or host, and a Kiln client to see the counts. Thanks Fuzen777 for the clean report (kiln#132).
- **Building from linked chests works, with or without Building Tools** (kiln#148). With a mod that links chests for building (Streamlined Logistics' Build From Linked Chests), blocks whose material is only in linked chests now show in the Construction Hammer's list with their count, the cursor shows the linked count before you place, the material catalogue counts them under Backpack & Magic Chests, All Materials and the amount sort (as before under Last Used and Favorites), and placing them pays from the bag and the base's Magic chests first (in the game's own order), then from the linked chests. Until now the list and the catalogue missed materials only the links held, and every placement that needed the linked chests was refused because Kiln turned down the game's placement transaction (kiln.log: "craft transaction did not check out (its accessors)"). With Building Tools 0.34.0, its placements now pay from the links too. If a placement is still left to the game, kiln.log says why as "block placement". Thanks to Fuzen777 for the clear report and logs.
- **Mods can make villagers and craftspeople say things in their own speech bubbles.** A mod on the server can show a
  line over an NPC's head (no voice), or have it greet with other lines, or not greet at all, while something holds (a
  hungry craftsperson complains instead of "Hello, Flameborn!"). You see it when your game runs Kiln, on a dedicated
  server and in a hosted world; a game without Kiln keeps the NPCs' normal lines. Thanks Marshall (Ryrin) for the request.

## Modders

- No API change (mod API stays 0.2.22). kiln.ui now hooks `SendInput` and `keybd_event`. A key press sent from the game's process while a Kiln text field has the keyboard doesn't reach that field, as a key or as a character. Characters sent as text (`KEYEVENTF_UNICODE`) still type. The game, Kiln's key handling and `KeyInput` listeners still get every sent key as before. kiln.log names the module that sent it (up to 3 lines).
- Stations (no managed API change): the C ABI grows by appending `KILN_STATION_FILL_ITEM`, `KilnStationRequest.item` (the old `reserved[0]`) and table member `fill_flags` (table 320 bytes); `source_stock(STOCK_FILLS)` now leaves out the Magic chests of the player's base; new capability `stations.fill_items`; new `kiln:craftstock` message 10 (older peers drop it).
- No API change (mod API unchanged). `CraftSourceOptions.Building` links now count in the build menu exactly where the base's Magic chests do. capability `crafting.build_ui` needs one more client symbol (`build/client.NoContainerKey`).
- A fault in a building hook (the build cursor's count, the build menu's rows) now also shows as `crafting.build_sources` or `crafting.build_ui` faulted, as documented (until now only kiln.log said so). A placement of more than 32 cost lines stays the game's payment and kiln.log says so.
- **Kiln.Npcs (new, mod API addition):** `Npcs.Say(npc, text, duration[, SayOptions])` puts your text in the game's own
  bubble over a friendly NPC for 0.5 to 60 s, with no voice-over, also when it is not the player's target.
  `Npcs.Speech(npc)` is your mod's override of that NPC: `Suppress()` (no greeting bubble, no greeting voice-over),
  `Replace(lines)` (it greets with your 1 to 32 lines), `Clear()`; several mods are ranked by `Priority`, then the most
  recent. Also `Npcs.StopSaying`, `SpeechOf`, `IsSaying`, `CanSpeak`, `Available`. Texts are a `string` or a `UiText` per
  language, no game text entry needed. The host decides; Kiln clients get it on the channel `kiln:npcspeech`
  (`required: false`), so a server mod is enough (`"clients": "none"`). Overrides and Says end when your mod unloads
  and when the world ends. The calls work on every side: do not put them under `Npcs.Available` (false on a dedicated
  server, which still sends). Lines: up to 200 characters per language and 2048 bytes of UTF-8 for all languages of a
  line together; a world shows up to 4096 distinct texts. Docs: `docs/kiln/services/npc-speech.md`; sample
  `mods/samples/HungryCrafter`. Requested by Marshall (Ryrin).
- **TestKit:** `KilnHarness.NpcSpeech` (`ModeOf`, `LinesOf`, `Saying`) reads what a Kiln client's bubble would be told.
- **Native:** new service table `kiln.npcspeech` v1 (`kiln_npcspeech.h`: `set`, `say`, `text`, `clear_all`, `status`),
  game client only; sigdb features `npcspeech.bubble` and `npcspeech.voice` (client 26430625).

## Not yet seen in a real game

- HadToRegister's setup (ShroudLink client add-on 0.8.1 with its Assistants key on T) on native Windows: the Wine harness plays the add-on's `SendInput` call and what Windows gives the game window for it, not a real key from a real desktop.
- The station rows lighting up and moving the right amount on a hosted world, a dedicated server and a joined client.
- The hammer's list, the cursor count, the catalogue tabs and a placement paid from linked chests in a hosted world, on a joined Kiln client (dedicated and hosted), with and without Building Tools 0.34.0.
- The whole client half: Kiln's text in the bubble, a Say over an NPC that is not the target, Suppress and Replace on a
  villager and on a craftsperson (with its voice-over muted), a joined Kiln client getting the host's state, and a
  vanilla client on the same server. Only the server half and the messages were checked (unit tests and a lab without a
  real client).
