# Kiln 0.2.0-dev.31.15

## Players

- **A lock's "Required: Lockpick" line turns green when a linked chest has the pick.** With a mod that links your chests for locks (Streamlined Logistics), a lock already opened from a linked chest, but the prompt's requirement line stayed red as if you had none. The game's HUD counts the item in your bag a second time for that line; Kiln now adds the linked chests there too, so the line shows the lock as met (and the count the press uses), on a world you host and when you join a Kiln server. Thanks Fuzen777 for testing it in a real game and pointing at the second count (#147).

## Modders

- No API change (mod API stays 0.2.22). The line's hook site `locks/client.LockRowCount` (sigdb `client.d/lock-sources.json`, pinned client 26430625) is not part of `items.lock_sources`: where it does not check out, only the line keeps the game's count (logged), and the lock checks, the locked prompt and the payment, a hosted world's included, keep counting the links. kiln.log logs the requirement line's state once per change: `locks: the lock prompt's requirement line counts the linked sources: ...` or `... counts the bag only: <check> ...`.
