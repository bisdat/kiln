# Kiln 0.2.0-dev.29.7

A patch for 0.2.0-dev.29.6: the Creative menu is there for the host again, a clearer note when ShroudForge is switched off, and game-folder mods no longer show "Will not run". The SDK stays at 0.2.0-dev.29. Everything else is as in 0.2.0-dev.29.6.

## Fixed

- **The Creative menu is there for the host from the start.** In a world your own game hosts (offline or co-op), the pause menu had no "Creative" entry and F7 offered no way to turn creative mode on until it was already on. Kiln now tells your game that you are the host as soon as your character is in the world.
- **Mods that Kiln places in the game folder show as running** (GitHub #41). Kiln puts some mods into the game folder for the game to load itself, such as AutolootCoop's powrprof.dll. They ran, but the launcher's mod list said "Will not run" and the load order listed them under "On, but not loading". They now show "Runs from the game folder"; "Will not run" stays for mods that really don't load.
- **EML mods that need ShroudForge say why they are skipped when `KILN_SHROUDFORGE=0` is set** (GitHub #36). The note told you to install ShroudForge. It now says that this environment variable switches ShroudForge off: remove the variable (setting it to 0 does not mean "default"), restart Steam and the Kiln launcher, and start the game again.

## Mod authors

- 0.2.0-dev.29.7 ships the launcher and the runtime only; keep using the 0.2.0-dev.29 SDK (mod API 0.2.4).
