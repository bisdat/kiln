# Kiln 0.2.0-dev.31.13

## Players

- **AMD FSR 4 on RX 6000 and RX 7000 cards.** Kiln now turns on the one Vulkan feature (compute-shader derivatives) that FSR 4's INT8 model and its auto exposure use. Before, FSR 4 could draw a black screen there (seen on an RX 6900 XT). Kiln also checks FSR 4's picture once after each set-up: if it comes out black or broken, FSR 3.1 runs instead for the rest of the game, and the readout and kiln.log say why. RX 9000 cards are unchanged.
- **Building Tools works next to Kiln again (thanks XHL).** Kiln no longer hooks the start of the game's build-cursor check, so Building Tools finds it and its overlap objects work. Kiln's building rules (/creative, building anywhere, free building) work as before. If you run Creative Mode and Building Tools together, kiln.log now says that Creative Mode keeps Building Tools' menu and tools wheel off; that one is between those two mods.
- **More of Building Tools works next to Kiln:** its full material list and partial area actions work again, a mod reading item details at startup no longer turns off its menu, and placements made through Building Tools follow Kiln's build cost and refund rules and can pay from linked chests (kiln.log says when a payment couldn't be traced).
- **Dedicated servers stop cleaner:** when a server stops, Kiln stops all its network traffic at once and drops what was waiting, and kiln.log says how much Kiln traffic went to and from each player when they leave. Map markers: a game whose server never answers now asks once a minute instead of every 5 seconds. Known game issue: if one player's connection goes bad, the game can run out of network packets for everyone ("packet pool is out of memory"); a stop then hangs after "Destroying a Player that requested a save game is BAD!" and must be ended by hand. Kiln can't prevent this yet.
- **Beastmaster runs on Kiln alone, without EMF.** Beasts attack at the Training Grounds and stop when petted, show their names and health on screen, on the compass and on the map, lose their debuffs when tamed, and beastmaster.spawn uses the camera's direction. Its three creature packs run on Kiln's own EML runner without ShroudForge, and texture-heavy EML mods cook about 5x faster because block-compressed textures now use every CPU core (same bytes; `KILN_EML_ENCODE_THREADS=1` restores the serial encode). Joined players need Kiln 0.2.0-dev.31.12 or newer for the markers.
- **Kiln's bundled ShroudForge cooks texture-heavy mods about 4x faster** (EMF Beastmaster's creature packs: 414 s to 95 s) by encoding block-compressed textures on every core with identical bytes (`KILN_SF_ENCODE_THREADS=1` restores the serial encode). It also no longer drops the Llama Harness, Camel Saddle and Mule Harness: a mod can now read a blob an earlier mod created in the same pass.
- **ShroudForge mods run again after a game update** when an older ShroudForge's settings or old backups were in the way: Kiln's ShroudForge converts the old toggle keys, takes the updated files as its clean copy when Steam's own manifest proves them, and otherwise says to verify the game files in Steam.
- **Reloading a mod re-applies its data packs.** `reload <id>` takes the mod's data-pack layers off and applies its current files, as an unload plus a load does, even for the last loaded mod. A reload whose new files don't all read keeps the old packs whole; Kiln.Quests and Kiln.Blocks data files follow reloads too.
- **Windows launcher:** Nexus downloads, the nxm:// link handler and Nexus update checks work again after the launcher ran as administrator, also on later normal starts; the Deck UI's folder browser no longer shows \\?\ paths.
- **Linux launcher:** when the launcher's page crashes, it reloads by itself; if it crashes again right away, the window shows "The launcher's page crashed." with Reload and Quit instead of staying black. The window always closes, and launcher.log records the reason, memory, uptime and system load.
- **The launcher no longer starts the game twice** if its page reloads during a "Just once: Vanilla" start: it keeps waiting for Steam, and a second Play is refused with "The game is already starting."
- **Open web panel:** each server's panel gets its own address, so sign-ins don't carry between servers; the one-time sign-in secret no longer goes on the command line; the connection closes when idle; profile data folders work. The admin pages (the map's health bars included) work under a strict Content-Security-Policy, and the Items and Map pages have a page heading for screen readers.

## Modders

- **Four new APIs, all from XHL's requests (mod API 0.2.22).**
  - **What the crosshair hits** (Kiln.Client `Crosshair`): the game's own crosshair hit from any thread: hit or miss, position, surface normal, distance, the entity or voxel material, with session, step and age so a stale read shows. It is the trace the stock cursor uses, and Kiln adds its hook only when a mod first reads it. C: `kiln.client.crosshair`.
  - **Game texts in any language** (Kiln.Content, Kiln.Items): every language the game ships (`Content.TextLanguages`, `LoadTextsAsync`, `TextIn`), an item's description, caption and lore next to its name in a chosen language (`Items.Description`, `DescriptionIn`, `DisplayNameIn`, `TextTags`), and the game's voxel materials by cell id with their loot item, exchange rate, placing items and a label (`Content.LoadVoxelMaterialsAsync`). Any thread, no game memory; a dedicated server answers clearly.
  - **Own a press until you let go** (Kiln.Ui): `KeyInput.Listen(..., KeyListenFlags.Own)`, plus `Pointer` for the left and right buttons, keeps a kept press's repeats and release from the game and other mods, and the game is not told the button is held while you drag. Focus loss, a world change and unloading end it safely. `PadInput.Read()` gives the controllers' sticks and triggers. C: `kiln.ui.input`.
  - **What a joined client knows** (Kiln.Blocks `ClientStations`, Kiln.Skills `ClientSkills`): read-only views of the stations near you and of your skill tree and points, also in someone else's world. C: `kiln.stations.client`, `kiln.skills.client`.
  Thank you, XHL: your references pinned down every game site behind these, and your mods showed exactly where Kiln was missing them.
- **EMF on Kiln:** EMF v39/v40 enemy orders and moves (kiln.creature_control leases), v33 markers (kiln.markers), v32 buffs and v35 player_view. EMF API parity is now 91 full, 28 partial, 25 not yet of 144.
- **Native mods that find game code by its bytes:** Kiln Rules' cursor waivers moved from `rules/CursorFlags`' entry to `rules/CursorFlagsStored` (entry + 0xfa). See docs/kiln/engines/README.md "Mods that find game code by its bytes" for the `sigdb/foreign` registry.
- **Kiln no longer detours the entry** of the material selector (`0x40e5d0`) or NativeTextLine (`0xb1da10`); it hooks inside them (`tools/MaterialSelectorBody`/`Done`, `build/client.MaterialRowsBody`/`Done`, `ui/NativeTextLineBody`). A native mod that redirects the game's calls of ApplyMaterials keeps Kiln's building rules working, as long as its DLL has unwind data.
- **`Network.Send` returns false** once the game's shutdown begins, between a server world's stop and the next world's start, and when 8192 frames already wait for the game.
- **C ABI:** `kiln_content.h` v4 slot `pack_mod_reloaded` (table 280 -> 288 bytes); `KilnPlayerBuff.reserved` is now `index` (same layout).
