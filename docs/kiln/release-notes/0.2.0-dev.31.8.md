# Kiln 0.2.0-dev.31.8

## Players

- **Packs install again when a mod changed its own Library folder.** Installing a pack again (by code or from its file) no longer fails with "the library did not take …" when one of its mods wrote its log or settings into its Library folder (seen with Loot Rarity Leveler). Kiln puts the mod's original files back and keeps your changed files in the Library's `kiln-changed` folder (the newest 3 copies per mod, each logged in `kiln-changed/changes.log`). It waits while a game or server that uses the mod is running.
- **Good to know:** reinstalling or repairing such a pack resets that mod's settings in the Library to the pack's. Your own copy is in `kiln-changed`. Pack and Crucible installs don't say so on screen yet; `changes.log` lists each restore.
