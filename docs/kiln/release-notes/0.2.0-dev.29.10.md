# Kiln 0.2.0-dev.29.10

A patch for 0.2.0-dev.29.9: mods made for CharosDX's dinput8.dll loader (Sparkworks Enhanced, Cross-Base Storage, Craft From Stations) are added to the Library as mods. The SDK stays at 0.2.0-dev.29. Everything else is as in 0.2.0-dev.29.9.

## Fixed

- **Sparkworks Enhanced, Cross-Base Storage and Craft From Stations are added as mods.** Their downloads carry the author's own `dinput8.dll`, which loads every `mods\<mod>\native\*.dll` in the game folder, and the mod itself in `mods/<mod>/native/`. Kiln's Library added that `dinput8.dll` as a native mod and left the mod out, so the mod never ran: the loader looked in the game's mods folder, where Kiln doesn't put mods. Kiln now leaves the loader out (it says it isn't needed) and adds each `mods/<mod>` folder as one native mod. It loads in the game and on servers, before Kiln hooks anything, as with its own loader. The mod's `config.ini` and `debug.log` are in its folder in Kiln's Library. If you added Sparkworks Enhanced with an earlier Kiln, remove the entry it made (named after the download) and drop the zip on the launcher again.

## Mod authors

- 0.2.0-dev.29.10 ships the launcher and the runtime only; keep using the 0.2.0-dev.29 SDK (mod API 0.2.4).
