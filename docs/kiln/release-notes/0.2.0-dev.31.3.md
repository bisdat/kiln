# Kiln 0.2.0-dev.31.3

## Players

- **Korean translation reviewed.** kraewon7422 reviewed the Korean translation as a native speaker and corrected 71 texts in the launcher and in the game: wrong meanings, literal renderings and wording a Korean reader would not use ([pull request 143](https://github.com/frostdev-ops/kiln/pull/143), #98). Thank you, kraewon7422!
- **EMF Lua mods work without EMF's Lua mod.** Kiln now ships EMF's unmodified Lua host 1.43.0 (from EMF 0.6.22) and uses it only when an enabled EMF Lua script needs it. A `lua` mod you add or switch off yourself still wins, Play without mods never runs it, and EMF's own loader keeps its own Lua mod. Thanks to matenm and the EMF contributors.

## Modders

- **`kiln new` installs missing templates again.** Newer .NET SDKs word their "no templates found" message differently, so `kiln new` stopped installing Kiln's templates on first use. It now knows both wordings, and a mistyped option value no longer triggers an install. The [first mod](https://frostdev.io/kiln/wiki/first-mod) page shows the one-line manual install too.

## Not yet seen in a real game

- The bundled Lua host with a real EMF Lua mod (such as Beastmaster) in a game client.
- `kiln new` against a .NET SDK that prints the newer message (covered by tests; the SDK we have prints the older one).
