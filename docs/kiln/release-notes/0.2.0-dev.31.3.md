# Kiln 0.2.0-dev.31.3

## Players

- **Korean translation reviewed.** kraewon7422 reviewed the Korean translation as a native speaker and corrected 71 texts in the launcher and in the game: wrong meanings, literal renderings and wording a Korean reader would not use ([pull request 143](https://github.com/frostdev-ops/kiln/pull/143), #98). A `lua` mod you add or switch off yourself still wins, Play without mods never runs it, and EMF's own loader keeps its own Lua mod. Thanks to matenm and the EMF contributors.
