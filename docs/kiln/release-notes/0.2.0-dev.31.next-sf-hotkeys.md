# ShroudForge mod shortcuts: press the key you want (for the next 0.2.0-dev.31 release)

## Players and server admins

- **Set a ShroudForge mod's shortcut by pressing it.** In Kiln's menu (Mods > a ShroudForge mod), click the shortcut box and press the key or the middle or a side mouse button you want, with Ctrl, Shift or Alt if you like. Kiln saves the code ShroudForge reads for that key on any keyboard layout, so no more `SDL:47`. Click the box again to stop waiting; Backspace, Delete or Unbind leave the mod without a shortcut. The mouse wheel and controller buttons are refused with the reason: ShroudForge's shortcuts read the keyboard and the mouse only. Typing still works: `Ctrl+G`, `F5`, `Mouse4` or the key's own character (such as `Ü`) are converted, and ShroudForge's own form (`Ctrl+SDL:10`) is taken as before. A shortcut Kiln cannot read now says so in plain words in every language. Thanks to netjunk for the report.
- **Key names follow your keyboard layout.** On a German, French or other non-US keyboard, the Keys page and ShroudForge shortcuts show the key as your keyboard labels it (`Ü` instead of `LeftBracket` or `[`), and switch when you switch layouts. What is saved does not change. Thanks to netjunk for the suggestion.

## Modders

- No API change. A ShroudForge `keybind` setting still stores ShroudForge's canonical text (`Ctrl+Alt+Shift+Meta+SDL:<scancode>` / `Mouse:<button>`); the in-game page converts readable input before it saves, and the shared package fixtures stay strict. `keybinds.json` keeps Kiln's stored key names; only the shown names follow the layout.
