# Kiln 0.2.0-dev.31.1

A patch for 0.2.0-dev.31 that helps us find why crafting from linked storage still fails for some players (#132). Mod API stays 0.2.17.

**Crafting itself doesn't change.** This patch only adds log lines. If crafting from linked chests still fails for you, send `kiln/logs/kiln.log` from your game client on GitHub or Discord.

## Players

- **Crafting with linked storage (#132): clearer logs.** When the crafting menu leaves a recipe to the game's own answer, `kiln.log` now says why: the recipe's layout or data couldn't be read, no matching payment was found, the game refused, a take or page read was missed, the cost or snapshot was bad, or the recipe was refused after Kiln added the linked materials. The lines are rate-limited. Thanks Fuzen777.
- **Other mods that patch the same game code.** When Kiln stands down because another mod changed a game function it hooks, `kiln.log` names the check that failed and, when it can tell, where the first changed byte leads. That's a hint, not proof of which mod made the change. Some mods keep their patches with their options switched off; to test without one, remove it.

## Modders

- **Mod API 0.2.17**, unchanged. No public ABI change.
