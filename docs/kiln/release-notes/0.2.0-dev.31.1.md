# Kiln 0.2.0-dev.31.1

A patch for 0.2.0-dev.31: mods that need a recent Kiln no longer show "Will not run", and new log lines help us find why crafting from linked storage still fails for some players (#132). Mod API stays 0.2.17.

**Crafting itself doesn't change.** For crafting, this patch only adds log lines. If crafting from linked chests still fails for you, send `kiln/logs/kiln.log` from your game client on GitHub or Discord.

## Players

- **No more false "Will not run".** The launcher and kilnctl took Kiln to be version 0.2.0-dev, which counts as older than every release, so a mod that asks for Kiln 0.2.0-dev.28 or newer (several XHL ports do) showed "Will not run" even on 0.2.0-dev.31. They now use the release's own version, so those mods load. A mod that really needs a newer Kiln is still refused. Crucible's version checks and modpack checks use the same version.
- **Crafting with linked storage (#132): clearer logs.** When the crafting menu leaves a recipe to the game's own answer, `kiln.log` now says why: the recipe's layout or data couldn't be read, no matching payment was found, the game refused, a take or page read was missed, the cost or snapshot was bad, or the recipe was refused after Kiln added the linked materials. The lines are rate-limited. Thanks Fuzen777.
- **Other mods that patch the same game code.** When Kiln stands down because another mod changed a game function it hooks, `kiln.log` names the check that failed and, when it can tell, where the first changed byte leads. That's a hint, not proof of which mod made the change. Some mods keep their patches with their options switched off; to test without one, remove it.

## Modders

- **Mod API 0.2.17**, unchanged. No public ABI change.

## Not yet seen in a real game

- The new crafting and stand-down log lines in a real game client.
- The "Will not run" fix in the launcher. kilnctl, built the same way, now loads a native mod that needs Kiln 0.2.0-dev.28 or newer and still refuses one that needs 0.2.0-dev.99.
