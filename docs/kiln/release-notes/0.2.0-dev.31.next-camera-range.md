# Kiln 0.2.0-dev.31.next: the camera's distance limit is gone

## Players and server admins

- **Mod cameras can now go anywhere.** A mod's camera (a cutscene, a follow view, a riding view) no longer has to stay within 250 m of your character, and Kiln no longer caps how far behind or above its target a follow camera sits. A mod can now show, for example, your whole base from 300 m straight up. What you see far from your character is the world as the game has it around you: things the server only sends near your character (creatures, other players, dropped items) can be missing in a view of a place far away.
- **A mod camera keeps going through a hitch.** A cutscene path or a camera shake used to stop when the game's simulation paused for a quarter of a second while the picture kept drawing. It now plays on. A camera that follows something still stops if it loses track of it.
- **Both ends need this version for the bigger numbers.** On a server, a mod's camera request for a player beyond the old limits is refused by a client that still runs an older Kiln; that player keeps the game's own camera.

## Modders

- No mod API change: mod API 0.2.26, as in 0.2.0-dev.31.24, and no signature or enum change. Only the numbers `Camera.SetLocal` and `Camera.Set` accept are different.
- **No distance from the player.** Path keys and every camera position Kiln derives (a profile's output, a shake on top) may be anywhere within the world bound, ±1,000,000 m on each axis, which stays: it keeps every position inside what the engine's 32.32 metres and float maths handle, and the map is about 10 km across. Outside it a request is refused `Bounds` before the first frame and ends `SafetyRejected` after it, as before.
- **No size caps on profiles and shakes.** `CameraProfile.Distance` is any finite value of 0 m or more (was 0.25 to 200), `OffsetLocal` and `OffsetWorldY` any finite metres (were 100 m and ±100 m). `CameraShake.AmplitudeMetres` and `FrequencyHz` are any finite value of 0 or more (were at most 0.5 m and 0.1 to 30 Hz); the offset is still never longer than the amplitude. How strong a shake may be is your call: a strong, fast one can be hard to look at.
- **Lens 1 to 179 degrees** (was 5 to 160): the whole degrees inside the 0.01 rad margin from 0 and 180 that the projection takes. The same for keyed lenses on a path.
- **A path and a shake read no player sample.** Only a follow profile reads a position, its target's, and still ends `SafetyRejected` when that copy is older than 250 ms; it no longer also needs the local player's copy when it follows something else. A path or a shake used to end `SafetyRejected` after 250 ms without a client step; now it plays on. End's blend out reads no sample either and always runs to its end. On a client whose position sampler is off or faulted, `camera.local_pose` and `camera.local_shake` stay on; only `camera.local_profile` goes off.
- **What a far camera costs.** Kiln moves the picture only. The server keeps streaming around the player's character (its `PlayerFocus`, which the game itself moves only for its own free camera and the build-mode spark), so a view far from the character can lack what the server sends only near the player. Culling and level of detail follow the drawn camera; Kiln never changes the near and far planes, and fog, sound and the HUD stay the player's. For a place kilometres away, move the player there first if the view must show its creatures and props. Details: [docs/kiln/services/camera.md](../services/camera.md#a-camera-far-from-the-player).
- **Both ends check the same numbers.** A 0.2.0-dev.31.25 server's request beyond the old limits is refused `Bounds` by an older Kiln client; `Camera.GetCapabilities` does not tell the two apart, so a mod that needs the new range should expect that refusal from older clients.
- **CameraSample's riding view** (`MountFollow.BuildFlyerProfile`) now frames any size of mount instead of refusing one taller than 100 m, farther back than 200 m or more than 250 m from the rider. The authoring schema (`schema/camera-override.schema.json`), the XML docs and the agent API index carry the new ranges.

## Not yet seen in a real game

- A camera far from the character: how far the game streams and draws at full detail around a Kiln camera, and what a view of a place kilometres away shows. Host tests and a static read of client 26430625 only (the server's focus follows the character, the game's free camera or the build spark).
- Lenses near 1 or 179 degrees, and shakes above half the frame rate, on screen.
