# Kiln 0.2.0-dev.29.20

This patch makes AMD FSR's "Auto" run FSR 3.1 until FSR 4 is confirmed in this game. FSR 4 stays a choice of its own, "FSR 4 (experimental)". Everything else is as in 0.2.0-dev.29.19.

**Not all of it checked in a real game yet.** This patch passed Kiln's tests and the release's own checks. On 0.2.0-dev.29.19 a tester's RX 9070 XT still drew dark scenes too dark with FSR 4, and FSR 3.1 looked right there, which is why "Auto" now runs FSR 3.1. The new choice itself has not been seen in a real game on an AMD card yet. If something looks or works wrong, tell us on GitHub or Discord with `kiln/logs/kiln.log`.

## Players

- **AMD FSR "Auto" runs FSR 3.1 for now, FSR 4 is "FSR 4 (experimental)".** With FSR 3 chosen in the game's graphics settings and AMD FSR chosen in Kiln, "Auto" now runs AMD FSR 3.1 on every card, until FSR 4 is confirmed in this game. Before, "Auto" ran FSR 4 where AMD's selection picked it (RX 9000, RX 7000, RX 6000 and recent AMD handhelds). To try FSR 4, choose **FSR 4 (experimental)** under **AMD FSR version**: on the Kiln menu's Graphics tab (Insert), on the launcher's Settings &gt; Graphics card, or in the Deck's Settings. It lets AMD choose as "Auto" did before (FSR 4 where your card and driver run it, else FSR 3.1), and it may render dark scenes too dark. If you had "Auto", you now get FSR 3.1 without doing anything. "FSR 3.1" stays as it was. In `kiln/kiln.json` the new choice is `"amdUpscaler": "fsr4"` under `"graphics"`. The switches in `kiln/control/amd` for testers stay as in 0.2.0-dev.29.19. Details: [graphics.md](../graphics.md#behind-the-games-fsr-3-phase-b).
