# Kiln 0.2.0-dev.29.8

A patch for 0.2.0-dev.29.7: clearer XHL and EML lines, and support reports that show where other mods changed the game's code. The SDK stays at 0.2.0-dev.29. Everything else is as in 0.2.0-dev.29.7.

## Fixed

- **XHL plugins no longer say "Requires XHL-Core" when XHL-Core is running.** Kiln's in-game Mods page showed a yellow "Requires XHL-Core…" line under an XHL plugin such as Remote Chest even when XHL-Core had started with the game. It now says that XHL-Core loads the plugin itself and where XHL-Core's own log is (XHL-Native-Plugin-Host.log); the warning stays when XHL-Core did not start.
- **The support report no longer lists a skipped EML mod as "off".** When the launcher had an EML mod on but Kiln could not apply it (for example ShroudForge switched off), the report's profile section said "off". It now says "on, not applied" with the reason.

## Changed

- **Support reports show where another mod changed the game's code.** `kiln/state/hooks.json`, which every support report includes, has a new `codePatches` list: each place where the game's code in memory differs from the game file, which module changed it, and for a redirected call what it called before. It helps find two mods that change the same spot (XHL Remote Chest's "could not prepare CALL 11" is such a case).

## Mod authors

- 0.2.0-dev.29.8 ships the launcher and the runtime only; keep using the 0.2.0-dev.29 SDK (mod API 0.2.4).
