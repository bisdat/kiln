# Kiln 0.2.0-dev.31.next (NPC speech bubbles; work-cm renames this file for the bundle)

## Players

- **Mods can make villagers and craftspeople say things in their own speech bubbles.** A mod on the server can show a
  line over an NPC's head (no voice), or have it greet with other lines, or not greet at all, while something holds (a
  hungry craftsperson complains instead of "Hello, Flameborn!"). You see it when your game runs Kiln, on a dedicated
  server and in a hosted world; a game without Kiln keeps the NPCs' normal lines. Thanks Marshall (Ryrin) for the request.

## Modders

- **Kiln.Npcs (new, mod API addition):** `Npcs.Say(npc, text, duration[, SayOptions])` puts your text in the game's own
  bubble over a friendly NPC for 0.5 to 60 s, with no voice-over, also when it is not the player's target.
  `Npcs.Speech(npc)` is your mod's override of that NPC: `Suppress()` (no greeting bubble, no greeting voice-over),
  `Replace(lines)` (it greets with your 1 to 32 lines), `Clear()`; several mods are ranked by `Priority`, then the most
  recent. Also `Npcs.StopSaying`, `SpeechOf`, `IsSaying`, `CanSpeak`, `Available`. Texts are a `string` or a `UiText` per
  language, no game text entry needed. The host decides; Kiln clients get it on the channel `kiln:npcspeech`
  (`required: false`), so a server mod is enough (`"clients": "none"`). Overrides and Says end when your mod unloads
  and when the world ends. The calls work on every side: do not put them under `Npcs.Available` (false on a dedicated
  server, which still sends). Lines: up to 200 characters per language and 2048 bytes of UTF-8 for all languages of a
  line together; a world shows up to 4096 distinct texts. Docs: `docs/kiln/services/npc-speech.md`; sample
  `mods/samples/HungryCrafter`. Requested by Marshall (Ryrin).
- **TestKit:** `KilnHarness.NpcSpeech` (`ModeOf`, `LinesOf`, `Saying`) reads what a Kiln client's bubble would be told.
- **Native:** new service table `kiln.npcspeech` v1 (`kiln_npcspeech.h`: `set`, `say`, `text`, `clear_all`, `status`),
  game client only; sigdb features `npcspeech.bubble` and `npcspeech.voice` (client 26430625).

## Not yet seen in a real game

- The whole client half: Kiln's text in the bubble, a Say over an NPC that is not the target, Suppress and Replace on a
  villager and on a craftsperson (with its voice-over muted), a joined Kiln client getting the host's state, and a
  vanilla client on the same server. Only the server half and the messages were checked (unit tests and a lab without a
  real client).
