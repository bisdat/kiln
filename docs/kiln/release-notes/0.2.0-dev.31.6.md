# Kiln 0.2.0-dev.31.6

## Players

- **No more save errors from a slow writer.** When Kiln writes mod data more slowly than the game saves (seen on a PC where something holds file renames for up to 20 s), kiln.log no longer logs an error at every autosave, and the launcher no longer counts them. You get one warning, a line when Kiln catches up, and a summary at most every 5 minutes. Nothing was lost before, and nothing changes in how your data is kept.

## Modders

- **Player storage faults.** `Saves.PlayerStoragePersistenceFailure` and the `saves.player_storage` capability now report a fault only when player storage could not be written, or is still not on disk 2 minutes after a world save, not while Kiln's writer is just slow. Kiln.Saves' timing lines now name the slowest file operation when one takes over 250 ms.

## Not yet seen in a real game

- The new delay, catch-up and summary lines in a real kiln.log, and the launcher's error count against a live log (covered by host and managed tests).
