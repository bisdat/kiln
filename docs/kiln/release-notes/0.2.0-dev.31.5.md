# Kiln 0.2.0-dev.31.5

## Players

- **Crucible and Nexus links open the launcher again.** Opening a Crucible pack link, or a Nexus Mods "Mod Manager Download" link, while the Kiln Launcher is closed starts the launcher and shows the pack preview or takes the download. In 0.2.0-dev.31.3 and 31.4 it started without the link.
- **One window per link.** A link you open while the launcher is already running goes to that window, once, and no second window opens.
- **Links for other games.** With Kiln set as the Nexus Mods link handler, a link for another game goes to the mod manager you used before again, instead of opening an empty Kiln window.
- **Packs with two mods of the same name install again.** A Crucible pack with two mods of the same name for different mod loaders (an EMF and a ShroudLink "expeditions", say) failed to install: one of them stopped with "larger than allowed", and the preview counted the missing downloads wrong. Each mod now gets its own file.
- **Repair kits and scrolls through mods.** Mods that use items for you can now use repair kits, and scrolls and mana grenades used this way now cost mana, as they do from the hotbar ([#118](https://github.com/frostdev-ops/kiln/issues/118), thanks Fuzen777).

## Modders

- **`Abilities.UseItem` and item costs (#118).** `UseItem` now covers `Consumable_RepairKit_T3` (used up by its PayUsageCost) and makes the item the use's cost item as the hotbar does, so scrolls and mana grenades pay their ManaCost. The game does not refuse when mana is short (mana goes to 0), so check `Abilities.Attributes.Get(player, AbilityResource.Mana)` first if you need to. Spells (ammunition) stay NotConsumable. The abilities docs list exactly which uses `UseItem` covers. C: `KILN_ITEM_USE_COST_ITEM` in `KilnItemUse.flags`; an older kiln.abilities answers INVALID_ARGUMENT for it. No C# API change.

## Not yet seen in a real game

- Links that start the launcher on Windows (tested with real Linux launcher builds).
- A repair kit's repairs raising durability, and the kit, scroll and mana effects in a game client (checked on a test server).
- Mana grenades through `UseItem` (covered by the game's data and the code, not run on a server).
