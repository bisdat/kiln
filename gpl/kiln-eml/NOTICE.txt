kiln-eml.dll: EML (Enshrouded Mod Loader) as a Kiln plugin

kiln-eml.dll is free software under the GNU General Public License, version 3 or (at your option) any later
version: kiln-eml.LICENSE.txt next to this file. It is a separate program from Kiln (MIT): Kiln loads it as a plugin
and talks to it only through its exported functions. kiln-eml-inspect (kiln-eml-inspect.exe on Windows), the read-only
archive inspector the launcher and kilnctl run before a start, is built from the same source under the same licence and
ships with this notice.

It is built from:
  - EML / kfc-parser v0.2.0 by Brabb3l, GPL-3.0-or-later,
    https://github.com/Brabb3l/kfc-parser (tag v0.2.0, commit 16708594d686b030d909f2d835b199d879ea9ad8),
    with the changes listed in gpl/kiln-eml/README.md (each marked "kiln-eml:" in the code);
  - kiln-eml's own code (gpl/kiln-eml/kiln-eml), GPL-3.0-or-later; its SF-dialect startup pass driver
    (kiln-eml/src/sf_pass.rs) and its startup type and asset sessions (kiln-eml/src/sf_startup/) adapt parts of
    ShroudForge (MIT, Copyright (c) 2026 bonsaibauer) at Kiln's fork pin 2df1de68, with the source paths and the MIT
    notice in their file headers; kiln-eml/src/sf_startup/format_adapter.rs adapts a file of bonsaibauer's kfc-parser
    fork (https://github.com/bonsaibauer/kfc-parser, commit db1580a98dcd679cb9f309b8e26fac97f0734de4, GPL-3.0-or-later);
  - sfi-core (crates/sfi/sfi-core) and the sfi-package crate it uses (crates/sfi/sfi-package), MIT,
    Copyright (c) 2026 Kiln contributors, including adaptations of ShroudForge (MIT, Copyright (c) 2026 bonsaibauer),
    with original source paths and pinned-source provenance in their file headers
    (linked into this DLL);
  - kiln-abi (crates/sfi/kiln-abi), MIT, Copyright (c) 2026 Kiln contributors: generated Rust bindings of Kiln's
    C headers, which kiln-eml's kiln.eml.archive table is declared with (linked into this DLL);
  - the Rust crates in gpl/kiln-eml/Cargo.lock, each under its own licence (THIRD-PARTY-NOTICES.txt).
    Lua bindings are deliberately aligned to mlua 0.11.6 / mlua-sys 0.10.0 /
    lua-src 550.0.0 (Lua 5.4); the before/after GPL dependency tests are in the source.

Corresponding source: gpl/kiln-eml, crates/sfi (including its workspace manifest and MIT licence),
tools/sfi/conformance, and native/core/abi with tools/sfi/abigen (the C headers kiln-abi's checked-in bindings are
generated from, and their generator) in Kiln's source archive of this release (kiln-<version>-src.tar.gz,
also https://github.com/frostdev-ops/kiln at the release tag). Build it with gpl/kiln-eml/build.sh (cargo xwin).

There is no warranty, to the extent permitted by law (GPL-3.0 sections 15 and 16).

Portrait renderer source: EMF 0.6.0, https://github.com/matenm/emf-enshrouded
commit bd6d90644785df80e4a61cb6ec55f9dab8e16b22, src/content/src/portraits (MIT source, combined here with GPL-3 EML).
